# Security policy

Please do not report a security vulnerability in a public issue or discussion.

## Report a vulnerability

Report it privately, in either of these ways:

* Use GitHub's
  [private vulnerability reporting](https://github.com/testflows/Machine/security/advisories/new)
  for this repository.
* Email `security@testflows.com`.

Include what is affected, such as the client, the Python SDK, the installer or
the service, the steps to reproduce the problem, and its impact as you see it.

## What happens next

We acknowledge your report, keep you informed while we investigate and fix
it, and tell you when the fix is released. Please give us a reasonable time to
fix the problem before you disclose it publicly.

## Scope

This policy covers the TestFlows Machine client, the Python SDK and its SDK
Core, the installer, the TestFlows Machine service, and the
[testflows.com](https://testflows.com) website.

Testing that disrupts the service or affects other users' accounts or data is
not permitted. See the
[Acceptable Use Policy](https://testflows.com/machine/legal/acceptable-use/).
