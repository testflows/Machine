# Contributor License Agreements

Each version of an agreement is its own file, named for the date it takes
effect, and is never changed after it is published. A contributor's
acceptance names the version they accepted, so every version stays here.

| Agreement | Current version |
|---|---|
| Individual CLA, accepted in a pull request | [CLA-20261110.md](CLA-20261110.md) |
| Corporate CLA, signed and emailed to `legal@testflows.com` | [CORPORATE-CLA-20261110.md](CORPORATE-CLA-20261110.md) |

A new version is a new file. The pull request template and CONTRIBUTING.md
then link it, and acceptances of earlier versions keep the terms they were
given under.
